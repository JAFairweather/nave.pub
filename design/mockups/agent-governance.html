The agent identity is bound into a salted scope hash, so this approval cannot be replayed to a different agent. Your signer creates the authority; this page never receives an nsec. Nothing is claimed active until it is read back from a relay.

Two facts this panel cannot yet state honestly. Membership for the middle three lanes is not in signed state — only counts are. And with no staging channel configured, quarantine holds rather than delivers, and nothing published says which. Four new public-safe fields close both.
A ladder, not a graph. The lanes are ordered by trust, and the interesting facts are which lane someone is in and what moves them up — a node-and-edge diagram would show topology instead. Two rules govern it: a visualization must import the thing it visualizes (the lane labels come from the module that classifies, exported the way the risk-tier spec is already shared between runtime, console and signing page), and (—), never (0) — a silent drop leaves no record, so a zero would claim knowledge of an unrecorded event. Why “Where” often says Hidden.

This approval names its channel as a salted hash, so a passer-by cannot tell which one it is. Enter the channel above and it will resolve. Kept verbatim — the model for privacy-by-construction disclosure.

The mirror pill is the one pattern the whole estate adopts. Ngage invented it and it is the only cross-plane mirror that exists today. Every write that should appear in a plane says, in words, on the row, whether it did — and offers a retry when it did not. Here it closes a real gap: an admission currently publishes a public 440 and nothing else, so it is invisible in Nvoy.
